## قواعد نگارش

- متن فارسی، با معادل انگلیسی اصطلاحات فنی در اولین کاربرد داخل پرانتز.
- هر ادعای کمّی باید به یک عدد قابل‌بازتولید در فصل ۹ وصل باشد؛ ادعای بدون عدد نوشته نمی‌شود.
- محدودیت‌ها صریح ذکر می‌شوند (نمونه: شبیه‌سازی مرحله‌ی پرداخت، متادیتای نمایشی بخشی از کاتالوگ).
- تصاویر و نمودارها از خروجی واقعی سامانه گرفته می‌شوند، نه شماتیک دستی.
