# نمونه‌ی صفحه‌ی ورود پنل

قالبی که پیش از بازطراحی صفحه‌ی ورود پنل ساخته شد: یک صفحه‌ی مستقل با Vite و Tailwind v4 که فرم کد تایید چهار رقمی را با پس‌زمینه‌ی تاریک و نور شناور نشان می‌دهد.

اینجا نگه داشته شده چون **ظاهر** آن به محصول راه یافت، نه منطقش. صفحه‌ی واقعی (`frontend/src/app/admin/login/page.tsx`) همچنان نام کاربری و رمز عبور می‌گیرد — ROADMAP بند ۴ می‌گوید یک ادمین و یک رمز در `.env` — و هیچ‌وقت کد چهار رقمی نداشته است.

## چه چیزی از این قالب برداشته شد

| از قالب | در محصول |
|---|---|
| پس‌زمینه‌ی مش تاریک با سه گوی تار شناور و شبکه‌ی ریز | `admin-auth-ground` / `admin-auth-orb` / `admin-auth-grid` |
| کارت شیشه‌ای با هاله و انیمیشن ورود از پایین | `admin-auth-card` |
| رینگ و درخشش هنگام فوکوس روی فیلد | `admin-auth-field` |
| دکمه‌ی گرادیانتی با لغزش نور | `admin-auth-submit` |
| لرزش هنگام کد نادرست | `admin-auth-refuse` |
| حالت موفقیت با تیک کشیده‌شده پیش از رفتن به مقصد | `admin-auth-done-*` |
| تایمر شمارش معکوس ارسال مجدد | `admin-auth-clock` — اما برای مهلت قفل شدن ورود، نه ارسال مجدد |

همه‌ی این‌ها در بخش «THE PANEL'S DOOR» در `frontend/src/app/globals.css` نوشته شده‌اند.

## چه چیزی برداشته نشد

**نارنجی.** قالب روی `#f97316` بنا شده بود؛ محصول طلای ترنجان (`--accent`) را گذاشت. یک سطح نارنجی خالص وسط برندی که همه‌جایش طلایی است، وصله می‌زند.

**عکس اتاق.** صفحه‌ی ورود پیش‌تر روی همان عکس پس‌زمینه‌ی پنل می‌ایستاد. عکس کنار رفت و زمینه‌ی تاریکِ این قالب جایش را گرفت — و کنتراست ضعیف‌ترین متن کارت از ۴٫۶۶:۱ به ۱۱٫۰۷:۱ رسید. عکس فدای عدد نشد؛ عدد از حذف عکس به دست آمد.

**منطق OTP.** بدون تغییر در بک‌اند، ورود با کد یعنی یک جریان تازه (ارسال کد، ذخیره‌ی موقت، تایید، سقف تلاش). این کار انجام نشد و صفحه همان جفت نام کاربری و رمز را می‌گیرد.

## اجرا

```bash
npm install
npm run build
```

خروجی در `dist/` ساخته می‌شود و `scripts/publish.mjs` آن را کنار `index.html` ریشه می‌گذارد. هیچ‌کدام از این دو در گیت نیست — مثل بقیه‌ی نمونه‌ها فقط سورس نگه داشته می‌شود.
