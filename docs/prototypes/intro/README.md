# نمونه‌های ورودی سینمایی

چهار الگوی تعامل که برای انتخاب روش ورودی ساخته و کنار هم مقایسه شدند. `chaptered.html` الگوی انتخاب‌شده است؛ سه تای دیگر برای ثبت مقایسه نگه داشته شده‌اند و در محصول نهایی استفاده نمی‌شوند.

| فایل | الگو |
|---|---|
| `chaptered.html` | **انتخاب‌شده** — صفحه قفل، هر اسکرول یک فصل را پخش می‌کند و روی صحنه‌ی بعدی می‌ایستد |
| `snap.html` | اسکرول آزاد، پس از توقف به صحنه‌ی بعدیِ هم‌جهت می‌چسبد |
| `scrub.html` | اسکرول پیوسته، فریم تابعی از موقعیت اسکرول (الگوی رایج) |
| `video.html` | ویدیوی خودپخش |

## اجرا

دارایی‌های سنگین در گیت نیستند. برای اجرا باید کنار این فایل‌ها ساخته شوند:

```bash
uv run --group ml python backend/scripts/extract_intro_frames.py assets/802-ezremove.mp4 docs/prototypes/intro/frames 137 1920 80
```

سپس چند تصویر فرش از `data/catalog-seed/cutouts/` را کنار همین فایل‌ها بگذارید (نام‌هایی که در کد صدا زده شده‌اند) و پوشه را با یک سرور ساده بالا بیاورید:

```bash
python -m http.server 8123
```

فایل باید از طریق `http://localhost:8123` باز شود، نه با دوبار کلیک — اجرای مستقیم از روی دیسک، بارگذاری فریم‌ها را مسدود می‌کند.

## پیدا کردن نقاط توقف

اگر فیلم عوض شد، صحنه‌هایی که ورودی باید روی آن‌ها بایستد را به‌صورت تصویر در `assets/` بگذارید و اجرا کنید:

```bash
uv run --group ml python backend/scripts/find_intro_stops.py assets/802-ezremove.mp4 assets docs/prototypes/intro
```

شماره‌ی فریم‌ها را چاپ می‌کند و یک تصویر مقایسه‌ای می‌سازد تا از درستی تطبیق مطمئن شوید. خروجی در `STOPS` داخل `chaptered.html` جایگزین می‌شود.

## آنچه پیش از تحویل باقی مانده

- حجم: ۱۸ مگابایت برای دنباله‌ی فعلی زیاد است. نسخه‌ی کم‌عرض برای موبایل و بررسی AVIF.
- حافظه: نگهداری همه‌ی فریم‌های ۱۹۲۰ پیکسلی در سافاری آی‌اواس تب را می‌بندد؛ یا فریم کوچک‌تر یا آزادسازی فریم‌های دور از نقطه‌ی فعلی.
- اجرا فقط در نخستین بازدید.
- مسیر خروج برای کیبورد و صفحه‌خوان، چون اسکرول در این الگو قفل است.
