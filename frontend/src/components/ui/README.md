# کامپوننت‌های پایه

فایل‌های این پوشه از کاتالوگ [21st.dev](https://21st.dev) گرفته شده‌اند و **هنوز به ترنجان تطبیق داده نشده‌اند** — عمداً همان‌طور که آمدند ذخیره شدند تا نقطه‌ی شروع دست‌نخورده بماند و تغییرهای بعدی در گیت قابل دیدن باشد.

| فایل | منبع |
|---|---|
| `product-card.tsx` | [beratberkayg/product-card-1](https://21st.dev/@beratberkayg/components/product-card-1) |
| `button.tsx`، `badge.tsx`، `card.tsx` | وابستگی‌های رجیستری shadcn/ui همان کامپوننت |

## چرا دستی ذخیره شده و با `shadcn add` نصب نشده

سهمیه‌ی رایگان ۲۱st **دو بار گرفتن کد در روز** است. هر بار اجرای دستور نصب، یک بار دیگر از همان سهمیه کم می‌کند؛ نگه داشتن فایل‌ها در مخزن یعنی این هزینه فقط یک‌بار پرداخت شده است.

```bash
npx shadcn@latest add "https://21st.dev/r/beratberkayg/product-card-1?api_key=$API_KEY_21ST"
```

## آنچه پیش از استفاده باید انجام شود

**وابستگی‌های نصب‌نشده:** `framer-motion`، `lucide-react`، `@radix-ui/react-slot`، `class-variance-authority`، `clsx`، `tailwind-merge`.

**فاصله‌ی این کد تا آنچه ترنجان لازم دارد** — هیچ‌کدام ایراد کامپوننت نیست، فقط تفاوت دامنه:

- راست‌به‌چپ نیست؛ همه‌ی `ml-`/`mr-`/`left`/`right` باید به معادل منطقی (`ms-`/`me-`/`start`/`end`) برود.
- قیمت با `$` و `toFixed(2)` نوشته می‌شود؛ ما تومان با ارقام فارسی و بدون اعشار می‌خواهیم.
- امتیاز و تعداد نظرات دارد — «نظرات کاربران» بیرون از دامنه‌ی پروژه است (بند ۶ نقشه‌ی راه).
- نشان تخفیف و «ارسال رایگان» دارد؛ سیستم تخفیف هم بیرون از دامنه است.
- سایزها برچسب پوشاک‌اند (`S`/`M`/`L`)؛ سایز ما ابعاد متری با قیمت و موجودی مستقل است.
- رنگ‌ها انتخاب‌شدنی‌اند؛ رنگ‌های ما رنگ‌های غالبِ استخراج‌شده از عکس‌اند و انتخاب‌شدنی نیستند.
- دکمه‌ی اصلی «افزودن به سبد» است؛ در ترنجان کنش شاخص «در خانه‌ی من ببین» است.
- رنگ‌ها از توکن‌های پیش‌فرض shadcn می‌آیند و باید به پالت «گچ و زغال» وصل شوند.
