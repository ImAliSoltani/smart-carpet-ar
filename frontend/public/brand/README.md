# دارایی‌های برند

فایل‌های این پوشه از **مسیر ثابت با نام ثابت** خوانده می‌شوند، طبق تصمیم نقشه‌ی راه: «جایگزینی نهایی باید تعویض یک فایل و اجرای یک دستور باشد، نه گشتن در صفحه‌ها.»

| فایل | کجا | نسبت | وضعیت |
|---|---|---|---|
| `hero-wide.webp` | قاب بزرگ کولاژ صفحه‌ی خانه | ۴:۵ | **جای‌نگهدار** |
| `hero-detail.webp` | قاب کوچک کولاژ، روی گوشه‌ی قاب بزرگ | ۱:۱ | **جای‌نگهدار** |

## جای‌نگهدارها

هر دو از عکس‌های کاتالوگ نمایشی بریده شده‌اند تا چیدمان با ابعاد واقعی ساخته و سنجیده شود. **این‌ها عکس تبلیغاتی نیستند** — نمای استودیویی محصول‌اند روی زمینه‌ی سفید، و جای دو عکس تبلیغاتی واقعی را پر می‌کنند تا صفحه پیش از رسیدن آن‌ها قابل ساخت باشد.

## جایگزینی

فایل نهایی را با همین دو نام اینجا بگذارید. هیچ کد دیگری عوض نمی‌شود.

- نسبت‌ها را نگه دارید (۴:۵ و ۱:۱)، وگرنه `object-cover` لبه‌ها را می‌برد.
- ضلع بلند حداقل ۱۶۰۰ پیکسل.
- **هیچ متنی داخل تصویر نباشد** (سند برند، بند ۷): متن‌های سایت با قلم واقعی روی صفحه نوشته می‌شوند، برای انتخاب‌پذیری و دسترس‌پذیری و سئو.
- پالت گرم و خنثی بماند تا کنار زمینه‌ی `#FAFAFA` ناهماهنگ نشود.

تبدیل به WebP، اگر ورودی JPEG بود:

```
uv run python -c "from PIL import Image; im=Image.open('hero-wide.jpg').convert('RGB'); im.thumbnail((1600,1600)); im.save('hero-wide.webp','WEBP',quality=86,method=6)"
```
