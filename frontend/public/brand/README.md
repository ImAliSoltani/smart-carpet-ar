# دارایی‌های برند

فایل‌های این پوشه با **import ثابت** خوانده می‌شوند (`src/app/page.tsx`)، نه با مسیر رشته‌ای. دلیلش: `next/image` یک import ثابت را با هشِ محتوایش آدرس می‌دهد، پس عوض کردن عکس آدرسش را هم عوض می‌کند و هیچ مرورگری نسخه‌ی دیروز را سرو نمی‌کند — همان چیزی که وقتی نام‌ها ثابت رشته‌ای بودند اتفاق افتاد و عکس قدیمی از کش می‌آمد. روال جایگزینی همان تعویض یک فایل می‌ماند، طبق تصمیم نقشه‌ی راه: «جایگزینی نهایی باید تعویض یک فایل و اجرای یک دستور باشد، نه گشتن در صفحه‌ها.»

|---|---|---|---|
| `hero-1.webp` | کارت راستِ بادبزن هیرو (کج، پشت) | ۴:۵ | ✅ نهایی |

## آیکون‌ها

سه فایل `icon-*.png` این پوشه به‌علاوه‌ی `src/app/icon.png` و `src/app/apple-icon.png` **خروجی اسکریپت‌اند**، نه دارایی دستی. هر ویرایشی رویشان با اجرای بعدی پاک می‌شود.

```
uv run python ../scripts/build_brand_icons.py      # از پوشه‌ی backend
```

فعلاً نشان را خود اسکریپت می‌کشد: یک ترنج با لبه‌ی کنگره‌دار، دو سرترنج، و یک مغز طلایی. سنجه‌ی پذیرشِ سند برند ۲۴ پیکسل است و همان شکلِ کشیده‌شده را تعیین کرده — کنگره‌ی کم‌عمق و جزئیات ریز در ۲۴ پیکسل ناپدید می‌شوند.

**نام برند داخل آیکون نیست و نباید برود.** سند برند (بند ۴) می‌گوید نام فارسی هرگز از ابزار تصویری خواسته نشود؛ ضمناً Pillow روی این ماشین `raqm` ندارد، یعنی اصلاً نمی‌تواند خط فارسی را به هم بچسباند و حروف جدا از هم درمی‌آیند.

### جایگزینی با لوگوی واقعی

طبق قاعده‌ی نقشه‌ی راه («تعویض یک فایل و اجرای یک دستور»):

1. لوگوی نهایی را **مربع، با پس‌زمینه‌ی شفاف (RGBA)** در `assets/brand/mark.png` بگذارید.
2. همان دستور بالا را اجرا کنید.

هر پنج خروجی از همان یک فایل ساخته می‌شوند. هیچ کد دیگری — نه منیفست، نه چیدمان، نه هیچ صفحه‌ای — عوض نمی‌شود.

کارت وسط بزرگ‌تر است و کامل دیده می‌شود؛ دو کارت کناری زیر آن می‌روند و لبه‌ی داخلی‌شان پوشیده می‌ماند. **بهترین عکس را `hero-2` بگذارید.**

## وضعیت

هر سه عکس تولیدشده و نهایی‌اند (۱۴۰۵/۰۵/۱۴): یک اتاق، یک نور، یک نیمکت — مجموعه یک صحنه است نه سه عکس. نسخه‌ی PNG اصلی هم کنارشان می‌ماند.

## جایگزینی

فایل نهایی را با همین دو نام اینجا بگذارید. هیچ کد دیگری عوض نمی‌شود.

- نسبت ۴:۵ را نگه دارید، وگرنه `object-cover` لبه‌ها را می‌برد.
- ضلع بلند حداقل ۱۶۰۰ پیکسل.
- **هر سه از یک نور و یک فضا باشند.** بادبزن سه عکس را کنار هم می‌چیند؛ سه عکس با سه نور متفاوت، سه عکس می‌ماند و یک صحنه نمی‌شود.
- **هیچ متنی داخل تصویر نباشد** (سند برند، بند ۷): متن‌های سایت با قلم واقعی روی صفحه نوشته می‌شوند، برای انتخاب‌پذیری و دسترس‌پذیری و سئو.
- پالت گرم و خنثی بماند تا کنار زمینه‌ی `#FAFAFA` ناهماهنگ نشود.

تبدیل به WebP، اگر ورودی JPEG بود:

```
uv run python -c "from PIL import Image; im=Image.open('hero-wide.jpg').convert('RGB'); im.thumbnail((1600,1600)); im.save('hero-wide.webp','WEBP',quality=86,method=6)"
```
